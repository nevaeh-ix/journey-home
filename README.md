# Journey Home 🎮

A choice-based survival game where you manage resources and make decisions while trying to make it home.

**Tech:** JavaScript, HTML, CSS

**Features:** Resource management, three changing regions, random events, and multiple endings shaped by your choices.

## Play locally

```bash
git clone https://github.com/nevaeh-ix/journey-home.git
cd journey-home
```

Open `index.html` in a browser. No installation required.
